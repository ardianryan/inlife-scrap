# Internship Scraper Console

Aplikasi pencatat dan penarik data pelamar magang secara otomatis dari portal mentor Inlife.

## Persyaratan Awal
Pastikan komputer Anda sudah terinstal **Python 3**. Jika belum, unduh dan instal dari [python.org](https://www.python.org/downloads/).
> **Khusus Windows**: Pastikan mencentang kotak **"Add Python to PATH"** saat proses instalasi dimulai.

---

## Cara Menjalankan Aplikasi

Aplikasi ini dilengkapi dengan skrip otomatis yang akan membuat Virtual Environment, menginstal pustaka yang dibutuhkan (`requirements.txt`), dan langsung membuka browser Anda.

### 🍎 Pengguna macOS / Linux
1. Buka aplikasi **Terminal**.
2. Masuk ke direktori folder ini:
   ```bash
   cd /path/to/folder/scrapinginlife
   ```
3. Jalankan perintah berikut:
   ```bash
   ./run.sh
   ```

### 💻 Pengguna Windows
1. Buka folder ini menggunakan **File Explorer**.
2. Klik ganda (double-click) pada berkas bernama:
   **`run.bat`**
3. Terminal Windows akan terbuka dan memulai proses setup secara otomatis.
